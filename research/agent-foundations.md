# Operational definitions of agent/individual/self — for coupled-fork XOR instrument

WIN: cited computable agent/individual/self definitions, ranked by cost/failure mode, for a fork+XOR world.

## 1. Interventional/counterfactual definitions

- **Kolchinsky & Wolpert, semantic info** ([1806.08053](https://arxiv.org/abs/1806.08053)): correlations causally necessary for viability, found by scrambling correlations, checking if a low-entropy viable set is still reached. Compute: per-subset scramble+resim, combinatorial. Fails: viability set externally chosen — circular.
- **Kenton et al., Discovering Agents** ([2208.08345](https://arxiv.org/abs/2208.08345), DeepMind): agent = a variable whose decision mechanism *adapts* if you intervene on the mechanism linking its actions to outcomes — mechanism-level, not object-level. Compute: intervene on outcome-mechanisms, check adaptive response, pre-built SCM. Fails: needs mechanism variables specified in advance.
- **Biehl & Virgo, POMDP-solvers** ([2209.01619](https://arxiv.org/abs/2209.01619)): agent iff an interpretation map makes state/action = optimal belief/action. Compute: search interpretations, under-constrained. Fails: certifies given a boundary, doesn't find one.
- **Orseau, McGill & Legg, Agents and Devices** ([1805.12387](https://arxiv.org/abs/1805.12387)): Bayesian model-selection, optimizer vs fixed I/O map. Compute: cheap MDL comparison on a trajectory. Fails: binary, no boundary notion.
- **Levin, TAME / cognitive light cone** ([2201.10346](https://arxiv.org/abs/2201.10346)): goal-directed = perturb, observe correction back to a target state; light-cone = largest deviation it corrects. Compute: perturb + measure return-to-setpoint. Fails: needs an external target/setpoint — same circularity as Kolchinsky. **Directly grounds #1.**
- **Krakauer et al., info theory of individuality** ([2020](https://link.springer.com/article/10.1007/s12064-020-00313-7)): individual = aggregate maximizing self-mutual-info I(pastₓ;futureₓ); organismal/colonial/driven forms. Compute: MI estimation, moderate, noisy at low N. Fails: needs the aggregate/boundary already given.
- **Rosas/Mediano ΦID** ([2111.06518](https://arxiv.org/pdf/2111.06518)): macro-variable emergent if it carries synergistic future-info no micro-part carries alone. Compute: exponential in variable count. Fails: tests a coarse-graining, doesn't propose one.
- **Hoel, effective information** ([PNAS 2013](https://www.pnas.org/doi/10.1073/pnas.1314922110)): macro "beats" micro if do-intervention EI is higher at that grain. Compute: cheap per grain; expensive to search grain-space. Fails: about determinism only, silent on repair.
- **Friston Markov blankets**: boundary-claim not licensed by the formalism — Bruineberg et al. split epistemic "Pearl blankets" from metaphysical "Friston blankets" ([BBS 2021](https://www.cambridge.org/core/journals/behavioral-and-brain-sciences/article/abs/emperors-new-markov-blankets/715C589A73DDF861DCF8997271DE0B8C)). Not recommended here.

## 2. Damage spreading — verdict: **PARTIAL (individuation, 2024+); NOT FOUND (levels)**
Damage spreading is mature (Kauffman RBNs; Derrida & Stauffer 1986 2D-CA phase transition; Lyapunov via Hamming distance, [cond-mat/9811159](https://arxiv.org/html/cond-mat/9811159v1)) but classifies a *regime* (frozen/critical/chaotic), not entities. Beer's GoL work ([2004, DOI](https://doi.org/10.1162/1064546041255539); [2015, Artificial Life 21](https://pubmed.ncbi.nlm.nih.gov/25148547/)) knocks out every cell around a glider, maps its "cognitive domain" from destructive/non-destructive response — characterizes ONE known entity, doesn't discover entities. **2024–2026 closes this partway**: Hamon, Etcheverry, Chan, Moulin-Frier & Oudeyer, *Discovering Sensorimotor Agency in CA using Diversity Search* ([2402.10236](https://arxiv.org/abs/2402.10236), Sci. Adv. 2025) uses **robustness to unseen perturbations as a selection criterion** to discover individuated agents from scratch — genuine perturbation-based individuation, still not levels. A GNCA self-maintenance study ([2607.12403](https://arxiv.org/abs/2607.12403), Entropy 2026) uses damage+transfer-entropy to trace repair flow, not individuate. Particle Lenia ([2305.16706](https://arxiv.org/pdf/2305.16706)) and Asymptotic-Lenia ([2407.21086](https://arxiv.org/pdf/2407.21086)) perturb only known entities. **No source pairs a healing-probability-vs-wound-radius curve with grading second-order/collective levels** — Selvedge's plateau test appears novel there.

## 3. MIRI agent foundations
**Cartesian Frames** ([2109.10996](https://arxiv.org/abs/2109.10996)): agent/environment split isn't primitive but *chosen* — factors world-states W = A×E; many frames coexist per W. Usable: for a candidate region, ask which "actions" determine outcomes independent of "environment" noise. **Finite Factored Sets** ([MIRI 2021](https://intelligence.org/2021/05/23/finite-factored-sets/)): generalizes Pearl-orthogonality to timeless sets — could formalize which torus cells factor independently without presupposing a grid/step boundary. **UNVERIFIED**: no source applies either as a runnable procedure on a cellular substrate; both remain conceptual.

## Ranked shortlist (cheapest → most expensive)
1. **Damage-spreading basin-of-healing** (Selvedge's own; grounds in Derrida-Stauffer+Beer+Levin+Hamon). Cost: O(1) fork+XOR per wound. Procedure: patch a cell, fork shared-RNG, run N steps, P(XOR→0) vs wound radius r; plateau = candidate level. **Individuate by clustering cells by which wounds they co-heal, not radius alone** — radius-only confounds a real self with mere correlation length (the scale-vs-entity trap that sank the lens). Misses: no semantics for *why* it heals; conflates "no damage" with "healed."
2. **Hoel effective information** at a candidate grain. Cost: closed-form calc once a partition exists. Misses: silent on repair.
3. **Orseau et al. agent-vs-device** on logged spark trajectories. Cost: cheap post-hoc. Misses: no boundary-finding.
4. **Krakauer temporal self-information** on aggregates from #1. Cost: moderate MI estimation. Misses: doesn't discover the aggregate.
5. **Kolchinsky-Wolpert viability-under-scrambling** to validate #1's candidates. Cost: highest. Most interpretive, run last.
